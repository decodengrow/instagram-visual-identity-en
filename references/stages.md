# Detailed methodology by stage

## STAGE 1. Forensic reference analysis

Analyze each reference separately before forming an overall direction. Don't draw conclusions from surface similarity.

### 1. Composition and visual hierarchy
Primary and secondary focal points; reading order; alignment; grid structure; text-to-image ratio; distribution of visual weight; negative space; margins and padding; symmetry and deliberate asymmetry; cropping and interaction with edges; information density; foreground vs background; how attention is directed.
→ Explain how the composition creates authority, tension, elegance, curiosity, clarity or emotional impact.

### 2. Typography as a system
Font categories and likely characteristics; serif-to-sans relationship; display vs text faces; contrast between typefaces; weights; tracking; leading; measure and line breaks; case; scale relationships between headline, subhead and body; alignment; italic, condensed, monospaced and expressive choices; oversized and deliberately cropped type; type as a graphic object, not only an information carrier.
→ Separate what is observed from hypotheses. Identify which choices drive recognizability most.

### 3. Color architecture
Dominant, supporting, accent and background colors; contrast and legibility; temperature; saturation; color blocking; tonal variation; monochrome vs multicolor; psychological and cultural associations; color for navigation and hierarchy.
→ Determine color's role: decorative, structural, symbolic or functional. Give HEX values only when confident; otherwise label them as provisional estimates.

### 4. Graphic language
Lines, frames, dividers, borders, geometric shapes, editorial annotations, captions and labels, numbering systems, arrows, diagrams, infographics, icons, textures, patterns, cut-out objects, collage, screenshots, photo treatments, grain and print effects, digital interface elements, layering and overlays.
→ Separate the fundamental components of the language from incidental ones.

### 5. Image direction
Photography style; subject choice; lighting; camera perspective; cropping; depth; contrast; processing and color grading; documentary vs staged; presence of people; use of architecture, objects, environment and abstraction; how photography interacts with typography.
→ Identify the underlying principles, don't just describe what's in the pictures.

### 6. Information architecture
How new ideas are introduced; how concepts are chunked; how supporting information is set apart; how repetition builds sequence and recognition; how section transitions are handled; how complexity is controlled; how the design adapts to long and short text; how the reader knows what to read first, next and last.

### 7. Brand character and visual semiotics
Axes: intellectual ↔ emotional; institutional ↔ independent; minimal ↔ expressive; restrained ↔ provocative; clinical ↔ human; technological ↔ artistic; luxury ↔ utilitarian; timeless ↔ experimental; authoritative ↔ approachable.
→ Name the visual signals behind each impression. Don't assume all audiences read the design the same way; separate solid evidence from subjective interpretation.

## STAGE 2. Cross-reference patterns

Comparison matrix columns:
1. Reference ID · 2. Dominant compositional principle · 3. Typography · 4. Color principles · 5. Graphic devices · 6. Image direction · 7. Information density · 8. Emotional character · 9. Most distinctive feature · 10. Potential for the target brand

Then:
- **A. Shared visual DNA** — recurring traits by category: structural, typographic, color, compositional, graphic, editorial, emotional.
- **B. Unique traits** — expressive features found in only one reference: adopt as a principle / adapt / exclude.
- **C. Contradictions** — conflicting elements (e.g. restrained editorial minimalism vs maximalist type and aggressive color blocks). Don't average them: decide whether the contrast can become a deliberate brand trait.
- **D. Principles without copying** — extract the logic; don't copy protected logos, proprietary illustrations or recognizable signature compositions. The goal is an original language inspired by the references, not a derivative copy.
- **E. Confidence** — for every significant conclusion: directly observed / confidently inferred / tentative hypothesis / cannot be determined.

## STAGE 3. Three creative directions

Three genuinely different, complete systems (not palette swaps). For each:
1. Name · 2. Core creative concept · 3. Brand persona · 4. Intended emotional response · 5. Typographic philosophy · 6. Compositional philosophy · 7. Color architecture · 8. Graphic language · 9. Photography direction · 10. Editorial design principles · 11. Carousel cover strategy · 12. Inner slide principles · 13. Data visualization · 14. Strategy for text-heavy posts · 15. Short announcements · 16. Weaknesses · 17. Long-term scalability · 18. How it differs from the references

Explain why each direction fits the brand and what trade-offs it involves. Finish by choosing the strongest and justifying the choice.

## STAGE 4. Visual identity architecture

### 4.1 Color system
Primary, secondary, accent, background, text, functional and data-viz colors; forbidden combinations. Provisional HEX + purpose of each.
Combinations for: headlines, body text, large background areas, charts, callouts/accent blocks, text over photos. Priority: legibility and deliberate contrast control (benchmark WCAG AA: 4.5:1 for text, 3:1 for large text). Judge "large" at display size, not canvas size: a 1080 px canvas shows at roughly 1/3 scale on a phone, so text under ~66 px on canvas (~52 px if bold) counts as normal text and needs 4.5:1. If an accent color only passes 3:1, define a darker text variant of it rather than using it for small text.

### 4.2 Typography system
Levels: display headline · H2 · section heading · body · captions · footnotes · labels · page numbers · numeric figures and metrics.
For each: font category, typeface characteristics, relative size, weight, leading, tracking, alignment, max line length, case rules.
Recommend accessible fonts (Google Fonts etc.). If a reference's typeface can't be identified, suggest alternatives without presenting them as fact.

### 4.3 Grid and layout system
Modular grid; outer margins; columns; alignment rules; spacing scale; text block proportions; image placement; safe zones (account for the 4:5 → 1:1 crop in the profile grid and Instagram UI overlays); slide numbering; headers and footers; rules for deliberate asymmetry; full-bleed images.
Give sizes as ratios and as pixels. The system must work across text volumes and topics.

### 4.4 Signature graphic elements
A small, considered set. For each: purpose, appearance, construction rules, placement, frequency, when to use, when not to use. Build recognition through consistent decisions, not decoration on every slide.

### 4.5 Consistency rules
- **Fixed:** core typographic relationships, color principles, grid logic, spacing principles, graphic language, editorial standards.
- **Flexible:** photography, layout variations, color pairings, information density, chart formats, cover treatments.

## STAGE 5. Instagram carousel system

No single formula for everything. Architectures:
- **A — Editorial essay:** text-led, authorial thinking.
- **B — Analytical breakdown:** research, evidence, complex concepts, expert explanation.
- **C — Provocative argument:** challenging conventional wisdom, an original position.
- **D — Case study:** results, transformations, measurable outcomes.
- **E — Methodology/system:** models, processes, frameworks.
- **F — Visual manifesto:** strong opinions, positioning, core brand ideas.
- **G — Data-driven carousel:** statistics, comparisons, benchmarks.

For each: use cases; slide count; cover composition; narrative logic; density; typography; variation options; when charts fit; transitions; ending strategy; CTA options; common design mistakes. Give an example structure with each slide described — templates don't have to be identical.

**Covers.** Options: oversized headline; editorial title treatment; strong typographic contrast; minimalism; image-led; data-led; numbered series; question headline; provocative statement; split layout; cropped type; high contrast. For each, say when to use it. A cover communicates the topic clearly and makes people want to swipe, without misleading clickbait.

**Inner slides.** Sustain attention through: progressive information, layout changes, typographic emphasis, visual pauses, charts, pull quotes, evidence panels, comparisons, annotations, carefully chosen images, changes in density. Variation must aid understanding, not exist for decoration.

**Closing slides.** Formats: brief summary; practical takeaway; final diagram or model; strong closing statement; discussion question; appropriate CTA; sources/reading list. Don't add a sales CTA automatically.

## STAGE 6. Post format system

1. Single editorial posts · 2. Large typographic statements · 3. Research and data graphics · 4. Case study graphics · 5. Educational diagrams · 6. Quote cards · 7. Announcements · 8. Sales posts · 9. Personal photos with editorial treatment · 10. Reels covers (account for the 9:16 → 4:5/1:1 crop) · 11. Stories (1080×1920, top/bottom safe zones) · 12. Recurring themed series

For each: how it inherits the identity and how it adapts to its job. No unrelated styles per content category.

## STAGE 7. Content-to-design translation

Start from meaning, not a template:
1. Core idea · 2. Audience · 3. Reader's starting knowledge · 4. Key takeaway · 5. Communication goal · 6. Volume and complexity · 7. Narrative architecture · 8. Visual format · 9. Information hierarchy · 10. Slide sequence · 11. A visual device for each slide · 12. Does the design support the meaning · 13. Is any important information lost · 14. Fit with the system · 15. Refine

Complex information → clarity over minimalism. A simple, strong idea → expression is allowed. Don't complicate where a simpler solution communicates better.

## STAGE 8. Technical design specs

For each carousel: goal; architecture; canvas size; slide count; content of each slide; heading hierarchy; text placement; alignment; background; colors; image requirements; graphic elements; chart requirements; transition logic; footer rules; accessibility and legibility.
Describe each slide precisely enough for a designer or an AI tool to reproduce the structure; give coordinates of main elements as % of the canvas (x, y, width, height).
Clearly separate what is specified from what still needs to be produced (this is a description, not an editable layout file).

## STAGE 9. Quality control

Score 1–10: 1. Visual hierarchy · 2. Typography · 3. Composition · 4. Brand fit · 5. Originality · 6. Phone legibility · 7. Information architecture · 8. Narrative flow · 9. Visual variety · 10. Use of negative space · 11. Accessibility · 12. Production feasibility.
Below 8 → reason + specific improvement.

Reject: generic AI aesthetics; unjustified gradients; random abstract shapes; decorative icons with no function; excessive text; inconsistent typography; arbitrary color changes; repetitive template layouts; visual noise; illegible footnotes; unnecessary stock photos; fabricated data or unsupported claims; decorative trends that weaken the identity.
Complexity is not a virtue in itself. The goal is meaning behind every design decision.

## STAGE 10. Master prompt template (deliverable section 15)

The master prompt must be self-contained — it gets pasted into a new chat without this research. Structure:

```
# [Brand name] — Instagram visual system, version [N]

## Role and goal
[who you are and what you do with new content]

## Brand
[what it does, audience, character — confirmed facts only]

## Fixed core
- Colors: [HEX + role + allowed/forbidden pairings]
- Typography: [fonts + hierarchy: px size on a 1080 canvas, weight, leading, tracking, case]
- Grid: [canvas, margins, columns, spacing scale, safe zones, headers/footers, numbering]
- Signature elements: [element — rule — when not to use]
- Editorial standards: [tone, line length, data sourcing]

## Flexible zone
[what may vary and within what limits]

## Carousel architectures
[A–G: when to choose, slide count, skeleton]

## Formats
[short rules for single posts, Reels, Stories, series]

## Process for a new post
[the 15 steps of stage 7, condensed]

## Output format
[slide-by-slide spec with % coordinates, copy, image requirements]

## Quality control
[12 criteria, threshold 8, reject list]

## System evolution
Change the core only deliberately: describe the problem, propose the change, note what it affects, bump the version number and record it in a changelog.
```
